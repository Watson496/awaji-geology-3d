# 淡路島の地質3Dビューア

淡路島の地表地質と、資料から推定した地下の岩体・断層をブラウザで表示します。岩体の表示を切り替えたり、任意の位置で切断して内部を見たりできます。

https://Watson496.github.io/awaji-geology-3d/

地下構造は、既存資料の解釈と仮定をもとに、個人が試作した仮説的なモデルです。学術的な正確さを裏付けるものではありません。

## ドキュメント

[ドキュメント一覧](docs/README.md)に、入門・目的別の手順・仕様・モデルの解説をまとめています。
