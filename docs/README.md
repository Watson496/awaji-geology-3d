# ドキュメント

公開ビューアは、ブラウザで淡路島の地質モデルを見るためのものです。初めて操作する場合は入門から、特定の操作や開発作業を行う場合は目的別の手順から参照できます。

地下構造は、既存資料の解釈と仮定をもとに、個人が試作した仮説的なモデルです。学術的な正確さを裏付けるものではありません。位置付けや推定の限界は[モデルの読み方と限界](explanation/model-and-limits.md)に記載しています。
