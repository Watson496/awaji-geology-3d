# 断面資料の追加

既存の図幅断面と同じ形式で、較正済みの断面資料をモデルに登録する手順です。画像と測線の距離・標高を対応付け、地質区分との対比を確認できる資料を対象にします。計算環境は[モデルデータの再生成](regenerate-model.md)で準備します。

## 登録内容

`data/structure/sections-extra.json` の `sections` 配列に断面を追加します。既存の `data/structure/sections.json` と同じ形式を使います。画像の切り出しや再配布について、元資料の利用条件も確認します。

各属性の意味は[追加断面の属性](../reference/data.md#追加断面の属性)に記載しています。原図の目盛りと測線を使い、画像上の位置を距離・標高に対応付けます。画像の追加だけでは地下構造の制約にはなりません。

## 制約点の登録

岩相内部の点は `picks`、断層の読み取りは `fault_picks` など、既存の登録形式に合わせて記録します。原資料から読み取った内容に加え、作成者が判断した地質区分との対比根拠と、計算用に置いた誤差設定を残します。対比できない境界は、特定の原区分へ強制的に割り当てません。

## 再生成と検査

断面登録後は、再生成処理に反映してモデルと表示データを作り直します。

```sh
npm run data
npm run model
npm run validate
```

検査結果の距離は、拘束に用いた断面の再現を調べる値です。[入力資料・制約点](../reference/sources.md)と[モデルの読み方と限界](../explanation/model-and-limits.md)に、既存資料の扱いを記載しています。
