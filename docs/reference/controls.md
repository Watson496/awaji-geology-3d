# 操作項目

操作パネルは「岩体」「レイヤー」「切断・断面図」に分かれています。複数の項目を同時に開くことができ、閉じても表示状態・不透明度・切断位置は保持されます。パネルを閉じる操作と鉛直倍率の設定は、パネル内のスクロールとは独立しています。

## 初期表示

採用モデルを表示し、岩体全体・地表地質図・断層線・地下の推定断層面を有効にしています。切断は設定していません。

## 岩体

岩体は和泉層群・大阪層群などのグループに分かれています。グループの表示切替と不透明度は、所属する岩体を一括して変更します。各行では岩体を個別に変更できます。100%は完全不透明、0%は非表示です。個別設定が混在している場合は「個別」と表示します。

「岩体を一括表示」は、岩体全体の表示を切り替えます。個々の岩体の表示・不透明度の設定は保持します。

一覧は原凡例の年代区分を使い、おおむね新しい時代から古い時代の順に並べています。同年代や年代範囲が重なるグループの並びは、地層の上下関係を示しません。検索では、閉じたグループも含めて地層名・岩体名・原記号を絞り込みます。

閉じた見出しの色見本は、同色の推定格子の体積を合算し、上位4色を表示します。残りは色数で示します。地表と岩体は同じ原記号・RGB値を保持しますが、照明や不透明度によって見え方が変わります。

## 地表地質図

岩体とは独立して、地表地質図の表示と不透明度を設定できます。100%は完全不透明、0%は透明です。地表だけを見る場合は、岩体を非表示にします。

## 断層線と地下の推定面

断層線は黒線で表示し、出典間の重複を整理しています。実線・破線の区別を保持し、岩体のあとに描画します。「地下の推定面」は、傾斜や外挿の仮定を含む地下断層面の表示切替です。

## 都市圏活断層図

国土地理院の公式afmタイルを地表に重ねます。表示切替と0〜100%の不透明度を指定でき、地表地質図と同じ座標範囲に配置します。原画像を参照する機能であり、赤い文字・矢印を断層ベクトルへ自動変換するものではありません。

## 鉛直切断

平面図のA・Bを結ぶ鉛直面で、岩体を切断します。「反転」で残す側を切り替えます。切り口では、岩体の地質区分と不透明度を保持します。

## 水平切断

指定した標高で上下に切り分け、「上側／下側」で残す側を選びます。表示標高は切断面と一致します。鉛直切断との併用が可能で、地表地質図・断層線・GLB出力にも同じ切断を適用します。X・Y固定面での切断操作はありません。

## 断面図と比較断面

「断面図」は、距離・標高軸付きの正面図の表示切替です。岩体・地表・切断の表示とは独立し、カメラも自動では切り替えません。3Dと同じメッシュを切り、原図の折れた測線を距離方向へ展開します。

「比較断面」は明石・洲本の計6断面から選べます。「原図」で、重ねた画像の不透明度を変更します。折れた測線と鉛直切断を併用すると、切断面は両端を結ぶ直線になり、平面図にはその線を破線で示します。

デスクトップでは、3D表示と断面図を幅380pxの操作パネルを除いた領域へ配置します。画面幅によるタブ切替は行いません。

## 切断のリセット

「切断をリセット」は、鉛直切断と水平切断を解除します。地表・岩体・断面図の表示や、選択した原断面は保持します。

## 出典・推定条件

使用資料・加工内容・利用条件と、ライセンス文書へのリンクを表示します。「検証用表示」には、入力点、シナリオ差、海域基盤面、検証用モデルの選択をまとめています。

「採用モデル」は、複数の仮定の組み合わせから通常表示用に選んだ設定です。内部名は `reference` です。比較A/Bは `shallow` / `deep` に対応します。比較を選んだときだけ「検証用」と表示し、変更する仮定は同じ設定欄に記載します。海域基盤面は、大阪湾の資料をもとに推定した音響基盤境界です。岩石の種類を示す地質区分とは別の補助境界として表示します。

## GLB

表示中の岩体・断面・断層・原図・海域基盤面と表示条件を保存します。実縮尺での出力には鉛直倍率1×を使用します。単位と座標の仕様は[データ形式・座標系](data.md)に記載しています。
