# 計算範囲・数値条件

このモデルの計算範囲と、推定のために置いた距離・厚さ・重みなどの仮定値を記載します。

## 格子と領域

陸域の標高範囲は−500〜＋700m、鉛直24層です。出力格子は約198×181×50mで、鉛直約71mのGemPy事前場を補間しています。地形の表示間隔は約100mです。

海域の補助構造領域は−3000mまでで、表示する音響基盤面は読み取り点から4km以内に限定しています。海域の計算上端0mは、海底の実測標高を示しません。

## 資料の近傍範囲

断面点の近傍窓の幅は500mです。資料に近い領域を記録するための便宜的な値で、岩体を切り落とす条件や、検証済みの信頼区間としては使いません。

## 岩体名の帰属

露頭セルから同じ地質区分の内部をたどり、有限断層による遮断を保つ最短経路で帰属を求めます。採用する到達距離は2km、競合する岩体への距離差は200mです。根拠が届かない部分や距離差の小さい部分は、原凡例別の「未区分」に残します。

## 被覆層の下の地質

採用する原単元の露出・登録断面制約への移送距離は、薄い／基準／厚いシナリオで1／2／3kmです。候補スコアの採用条件は、パッケージ比率0.5以上、岩相比率0.5以上、同一パッケージの次候補との差0.15以上です。正規化スコアは確率ではありません。

## 比較モデル

比較A/Bの内部名は `shallow` / `deep`、採用モデルは `reference` です。浅い／深いシナリオでは、原単元ごとに計算するGemPy事前場の仮想基底深度を0.65倍／1.4倍とし、断層ごとの明示した角度幅と、海域基盤深度±300mを使います。傾斜方向が不明な断層について、根拠のない傾斜方向を追加する処理はありません。

## 表層堆積物の厚さ

単位はmです。基準値と薄い／厚い仮定は感度分析の設定であり、各地点の実測厚さや確定上限ではありません。

| 原区分 | 薄い仮定 | 基準 | 厚い仮定 |
| --- | ---: | ---: | ---: |
| 盛土・埋立地 `H2_or` | 2m | 8m | 15m |
| 谷底・海岸低地堆積物 `H_sad` | 15m | 30m | 60m |
| 古い段丘 `Q31_std` | 20m | 40m | 80m |
| 新しい段丘 `Q32-33_std` | 15m | 35m | 70m |

## 表示用の断層線

出典間で400m以内、方向差25度以内の区間を重複候補として照合します。同じ原資料内の別枝や並走線は、この処理で間引きません。

## 地下断層面

原断面から求めた曲線の沿走向補間には、距離重みと3kmの減衰長を使います。断面姿勢がない場合に参照する近隣資料は、距離20km以内、走向差35度以内を対象にします。角度・傾斜側の候補と、外挿の仮定は `data/structure/faults.json` に記録しています。

## 表示メッシュ

共通カテゴリ場に3回の対称拡散を行い、X/Y方向の重みは0.05、Z方向は0.01としています。拡散は断層で遮断します。marching cubesと断面等値線の三角形化で面を生成し、任意断面は表示メッシュとの交線から求めます。

表層堆積物の厚さの仮定は[地下構造の推定](../explanation/structural-model.md#表層堆積物の厚さ)、資料の誤差設定は[入力資料・制約点](sources.md)に記載しています。
