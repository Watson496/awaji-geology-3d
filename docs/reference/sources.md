# 入力資料・制約点

使用した資料と、そこから取り込んだ線・点の範囲を記載します。資料の利用条件と加工者は[出典一覧](../../web/data/ATTRIBUTION.md)に記録しています。元資料に記載された情報と、作成者による読み取り・地質区分の対応付け・誤差の設定を分けて記載しています。以下のパスはリポジトリのルートを基準にしています。

## 地表地質と地形

標高は国土地理院DEM10B、地表地質はシームレス地質図V2の原区分を使います。地表の分類は、5万分の1図幅の別分類で上書きしません。走向傾斜は通常の堆積層のものを使い、片理・節理・逆転層は混ぜません。

## シームレス地質図の断層線

シームレス地質図V2の公式シェープファイル4区画（5134・5135・5234・5235、2025-07-18版）から、実在・伏在・推定断層の原頂点を取得しています。海岸線・通常の地質境界・撓曲を断層に混ぜません。`.prj` のJGD2000をEPSG:32653へ変換し、領域境界で切る以外の頂点の手直し・端点直線化はしません。対象範囲には187レコード群を含みます。

## 地質図Naviの断層線

地質図Naviが実際に読み込む `af_segment.json`（活断層データ）と `JPF_2024.json`（全国主要活断層帯）を別レイヤーとして取得しています。範囲内はそれぞれ12・44フィーチャです。元データの位置には概略化されたものも含まれます。陸上の地下計算では、同じ断層が重複する場合に詳細な地質断層線を優先します。地質断層線がない中央構造線の海域は、主要活断層帯の個別線を構造候補に使います。

## 中央構造線の原トレース

中央構造線断層帯は、全国主要活断層帯のデータに収録された各枝の原線を使います。分断・並走した線をそれぞれ保持し、地下の面も枝ごとに扱います。

## 図幅との照合

5万分の1図幅の名前・傾斜情報は、公式の線と最大標本距離250m以内で空間照合できた場合の対比仮説として使います。地下面には傾斜・外挿の事前仮定が残ります。照合結果と距離を保存し、図幅の線でシームレスの線の位置を上書きしません。

## 国土地理院の解説書

国土地理院都市圏活断層図の解説書（2014）も取得し、洲本・由良・鳴門海峡の活断層分布・変位様式を参照しています。
`data/structure/faults.json` に面群ごとの線・傾斜プロファイル・拘束深度・出典・仮定を記録します。面は有限の三角形で計算し、線の端から無限平面を延ばして島全体を分断する処理はしません。

## 図幅断面の座標化

明石図幅のA–B断面を使います。`sec.shp` は平面位置だけに使い、元画像のA/B軸・海水準・±500m目盛りと対応付けました。地質境界の読み取りには、図中に境界として描かれた線を使います。画像の枠や着色領域の端は、制約点に含めません。

NGd（野島花崗閃緑岩）の岩相内部4点を使います。
岩屋層とNGdの基底接触3点を使います。
野島・中持・楠本断層の断面内の曲線を地下形状の制約に使います。他の登録断面も含め、9断層・10曲線を使用します。公式地表トレースは移動させず、原断面との位置合わせ量と曲線の再現誤差を別々に記録します。

明石C–D–E・F–G、洲本A–B・C–D–E・F–G–Hも座標化し、原図を比較できます。NGdとSGdの計13個の岩相内部点は、塊状花崗閃緑岩/トーナル岩との対比仮説（誤差を150mとした設定）として入力します。曖昧なST・TS等を原単元に強制対比しません。洲本A–Bは原図との比較に使い、地下制約点は登録していません。

断面全体をデジタイズしたものではありません。原図のピクセル位置・距離/標高の較正・3D座標・地質区分の対比根拠・誤差は `data/structure/sections.json` に保存します。岩相/境界には100m、断層曲線の読み取りには150mという誤差設定を置いています。これらは本モデルで仮定した値であり、読み取り精度を実測した結果ではありません。曖昧なKG（花崗岩・花崗閃緑岩）を一つの原単元に強制対比しません。岩屋層の年代の対応付けには、2000年の化石年代研究を参照しています。

断面の制約は仮想深度の事前場より強い重みで入力します。境界点は接触両側の場のゼロ値を拘束します。

断層の地下への延長と海域の基盤境界については[断層・海域の推定](../explanation/faults-and-marine.md)に記載しています。
