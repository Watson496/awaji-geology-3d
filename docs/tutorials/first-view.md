# 初めての地質モデル

岩体の不透明度を変えて内部を見たあと、鉛直切断と断面図を使います。この練習では、公開ビューアをブラウザで開くだけで操作できます。

https://Watson496.github.io/awaji-geology-3d/

## 初期表示

ページを開き、地形と色の付いた岩体が表示されるまで待ちます。初期表示では、地表地質図・岩体・断層線・地下の推定断層面が有効になっています。

色は地質の区分を表します。地下の岩体は、既存資料の解釈と仮定をもとに推定した形状です。

## 岩体の不透明度

操作パネルの「岩体」を開き、和泉層群などのグループを展開します。グループの不透明度を100%から下げると、そのグループの岩体が透けて見えます。個別の岩体の不透明度も変更できます。

変更した不透明度を100%に戻します。グループ全体の操作と個別の操作の違いを、同じ場所の表示で確認できます。

## 鉛直切断

「切断・断面図」を開き、「鉛直切断」を使います。平面図のA・Bをドラッグすると、2点を通る鉛直面で岩体が切れ、内部の地質区分が見えるようになります。「反転」で残す側を切り替えます。

切り口で色が切り替わる位置は、資料の読み取りと仮定から、このモデルで組み立てた地質境界です。

## 断面図

「断面図」をオンにすると、距離と標高の軸が付いた図が画面下部に表示されます。3Dの視点を変える操作とは独立して、断面を正面から確認できます。

最後に「切断をリセット」を押します。鉛直・水平の切断が解除され、岩体の表示状態と断面図の選択は保持されます。

操作項目の意味は[操作項目](../reference/controls.md)、推定結果の受け取り方は[モデルの読み方と限界](../explanation/model-and-limits.md)に記載しています。
