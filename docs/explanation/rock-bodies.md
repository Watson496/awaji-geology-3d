# 地質区分と岩体名

地質図の色分けは、年代や岩石の種類による区分を表します。同じ区分の場所が、すべて同じ名前の岩体に属するとは限りません。このビューアは、色分けに使う区分と、個々の岩体を識別する名前を分けています。

シームレス地質図の凡例IDは地質区分であり、個々の地層・岩体の識別子ではありません。例えば明石図幅の野島花崗閃緑岩（NGd）と洲本図幅の洲本花崗閃緑岩（SGd）は、どちらも `K21_pim_a` に対応します。別の岩体IDを付け、同色・同じ原凡例でも表示と不透明度を独立して管理します。先山花崗岩は洲本図幅のSGで、SGdとは別です。

大阪層群は富島・仮屋・愛宕・五色浜、和泉層群は北阿万・西淡などを図幅の地質単元に基づいて対応づけます。図幅の範囲外や対比を支持できない部分は、累層・岩体名を強制的に付けません。岩屋累層の分布は明石図幅を参照し、年代の対応付けには[入力資料・制約点](../reference/sources.md)に記載した化石年代研究を使います。

地下の岩体名は、地表の区分と図幅資料の対応を作成者が解釈し、その対応が地下へ続くと仮定して割り当てています。`scripts/rock_bodies.py` が、明石1990・洲本1992の `geo_A` と原凡例が一致する露頭セルを起点に、推定済みの3Dモデルの同じ地質区分内で、有限断層の遮断を保った最短経路を求めます。各図幅記号と許容する原凡例はコードに明記し、単一セルの偶然の重なりは採用しません。

到達距離2kmと競合する岩体への距離差200mは便宜的な帰属仮定です。近い二つの岩体の中点を確定境界にせず、距離差が小さい部分や支持の届かない部分を原凡例別の「未区分」に残します。この帰属範囲の端を、観測された貫入境界や累層境界と解釈してはいけません。「未区分」は名称の未確定、「未拘束」は地質区分そのものの未確定で、別の属性です。

関連するIDとファイルの仕様は[データ形式・座標系](../reference/data.md)に記載しています。
