# 地下構造の推定

このモデルでは、地表地質や断面の読み取りに、作成者が置いた連続性や地層の上下関係の仮定を組み合わせ、地下の形状を試作しています。以下は、その形状を得るために実装した計算方法の説明です。

## 構造と原凡例

シームレス地質図の22単元についてGemPyで分布を表す数値場を計算し、補間の手掛かりとなる「事前場」として使います。事前場が結果へ与える影響には範囲と重みを設け、地表・断面の資料や地層の上下関係と組み合わせて、各格子の地質区分を選びます。

### 構造上のまとまり

原凡例とは別に、基盤の火成・変成岩集合、和泉層群、古第三系、新第三系、更新統、段丘、完新統、人工地盤の9つの構造上のまとまりを定義します。このまとまりは構造推定に使い、表示では元の地質区分を保持します。

### 共通の分布場

各まとまりの共通の分布場を、地表ラベル・断面の岩相/接触点・海域の基盤境界と、断層で遮断したグラフ上の補間で求めます。グラフ辺の断層面との交差を計算し、交差する辺の伝達をゼロにします。断層は表示だけでなく推定演算子を変えます。

### 累重関係

断層を横切らない鉛直区間について、このモデルで仮定した堆積体の上下関係を、計算上の制約として同時に最適化します。途中の地層が欠ける不整合は許し、逆順の累重は許しません。断層を跨ぐ位置では順序制約を切るため、異なる年代の構造が接することができます。

### まとまりの内部の岩相

決定した構造の内部で、原凡例の岩相を選びます。和泉層群の礫岩・泥岩・砂泥互層・砂岩や、同年代の花崗岩相は、それぞれの分布の候補として扱います。

### 基盤内の貫入関係

基盤内では、図幅・研究に対応する古期片麻状花崗岩類→塊状花崗閃緑岩→塊状花崗岩の貫入関係を、支持領域の重複部分の優先関係として扱います。原記号と個別岩体の対応を広域に一般化する部分は仮定として記録します。

### 未拘束の領域

選択された構造内で原単元を支持できない場所は灰色の「未拘束」にします。

このため、構造の共通境界と原凡例の分類は別のデータです。`structural-packages.bin` と `volume.bin` を別々に出力します。構造関係と出典は `data/structure/topology.json` に記録します。

断層による不連続は、SciPyを使う補間処理で、断層面を横切る格子間の伝達を遮断することで表現します。断層面の設定と地層の上下関係は、作成者がこの試作に与えた条件です。

## 被覆層と下位地質

沖積層・段丘堆積物・盛土の分布と、その下の地質構造を別の場として推定します。被覆地点では下位地質を未観測として扱います。下位構造の地表境界に使うのは露出している古い原単元だけです。原断面から登録した岩相・接触点は、解釈に基づく軟らかい制約として併用します。

下位構造は、有限断層面で遮断した3Dグラフ上で解きます。露出している地質区分を境界条件とし、GemPy事前場を補間の手掛かりに使います。被覆層より古い5つの構造上のまとまりから、仮定した上下関係に従って候補を選び、その内部で岩相を選択します。露出地では地表の区分を保持し、被覆地点では推定した下位構造に有限厚さの被覆層を重ねます。

採用する原単元そのものの露出・登録断面制約へ、断層を横切らない経路で到達できることを必要とします。移送距離の仮定は薄い/基準/厚いシナリオで1/2/3kmです。正規化した候補スコアのパッケージ比率0.5以上、岩相比率0.5以上、同一パッケージ内の次候補との差0.15以上を採用条件にします。距離・閾値は推定上の仮定で、正規化スコアは確率や較正済みの信頼度ではありません。観測のない断層ブロック、範囲外、競合する岩相は区分未確定のまま残します。有限断層面の端を回り込む経路は可能です。

条件は `data/structure/substrate-policy.json` に、結果は各シナリオの `substrate-volume.bin`（原単元ID）、`substrate-distance.bin`（採用単元の制約までのグラフ距離、float32/m）、`substrate-status.bin`（採用・競合・距離外・制約なし等）に保存します。未確定セルの距離は最寄りの利用可能な制約までの距離です。`metrics.json` の `fault_conditioning.substrate` は被覆単元ごとの未確定率、ソルバー残差を記録します。

## 表層堆積物の厚さ

沖積層・段丘堆積物・盛土の厚さは、累重順序だけでは制限できません。このモデルでは、パッケージを選ぶ段階で、局所DEMからの深度による有限厚さの仮定を課し、断層で上下関係をリセットする場合も適用します。厚さの制限は対象の若い地質区分に適用します。下位の岩相を支持できない場合は未確定区分にします。

明石（1990） p.54には浦川沿い3〜4m・10m、富島5m・6〜7m、育波11m、仮屋約10mの沖積層が記載されています。p.46〜47には江崎の段丘堆積物16m、22.5m以上、15m以上などの記載があります。洲本（1992） p.62〜66では段丘堆積物の数m〜10m前後の事例、p.68では郡家11.5m・多賀7.6m・大谷12m・志筑4mの沖積層が記載されています。局所事例は島全域の最大厚さではなく、「以上」は基底未確認の下限です。これらの観測地点の座標と基底形状は、このモデルの制約点には含めていません。

[厚さの設定値](../reference/parameters.md#表層堆積物の厚さ)は、局所資料が示す厚さの規模を参考にした地域的な感度分析の仮定です。各地点の実測厚さ・確定上限・信頼区間ではありません。大阪層群などの古い厚い堆積層には同じ制限を適用しません。出典PDFのハッシュ・本文頁・記載の意味・仮定値は `data/structure/surficial-cover.json` に記録しています。

鉛直50m格子では数m厚の層は解像できません。地表原区分を維持する最上セルには例外を設け、薄層が一セルで表現されることを明記しています。最上セルは最大約50m厚の区画であって、実測50m厚という意味ではありません。各シナリオの `metrics.json` にセル中心の最大深度と下端深度の上限を記録します。細かな基底形状には局所的な格子細分化・ボーリングや図幅の基底線の座標化が必要です。

## 表示メッシュ

表示用の面を滑らかにする処理でも、断層を横切る拡散を遮断します。任意断面は、3D表示と同じ岩体メッシュと鉛直面の交線から求め、穴を保持して三角形化します。平滑化を行っても、元格子に由来する不確実性は残ります。

数値条件の一覧は[計算範囲・数値条件](../reference/parameters.md)に記載しています。
