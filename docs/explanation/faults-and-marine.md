# 断層・海域の推定

地表に描かれた断層線だけでは、地下の傾斜や曲がり方までは決まりません。この試作では、図幅の断面や地域資料から読み取った姿勢を手掛かりにし、資料のない部分へ延長する形状には、作成者が置いた補間・外挿の仮定を使っています。

## 断層線の表示統合

表示は出典別に分けず、`npm run fault-display` で作る共通カタログを地表・岩体・平面図に使います。原ベクトルと地下計算用の面は保持し、地質図の詳細トレースを地域概略線より優先します。異なる出典間で400m以内かつ方向差25度以内の区間を表示上の重複候補として置き換え、未対応部分は残します。同じ原資料にある別枝・並走線はこの処理で間引きません。これは表示用の照合仮説で、断層の同一性や地下接続を地質学的に確定するものではありません。

同じ名前の地質断層はまとめ、志筑・先山の活動セグメントは対応する名前に統合します。複数断層を含む広域セグメントを無理に一断層の名前にしません。中央構造線は個別の10枝を使い、地下の面を枝ごとに保持します。`web/data/fault-display.json` に原資料ID、採用区間、置換先、除外延長、入力ハッシュを記録します。色は黒で統一し、実線・破線の意味は残します。

## 地下の断層面

明石A–B・C–D–E・F–Gと洲本C–D–E・F–G–Hに描かれた、9断層・10本の断層曲線を座標化しています。読み取る対象は、図中で断層として描かれた曲線です。地表線と断面線の交差から局所的な走向を取り、断面で見える見かけの傾斜を3Dの法線方向の変化に変換します。久野々断層はC–D–EとF–Gの各地点で異なる姿勢を持ちます。

深度ごとの法線方向のオフセットを原曲線から求め、同じ断層の近傍で補間します。地表の線の位置を固定したまま、断面から得た地下の変化量を補間します。沿走向の距離重みと3kmの減衰長は明示したモデル仮定です。5万分の1断面と20万分の1地表線の位置差は、地表交点での水平登録量として別記録します。原座標での距離と登録後の曲線再現距離を区別し、登録後の小さな誤差を地下の独立した精度にはしません。現在のDEMより上に来る原図点や計算下端より下の点も、検証の適用範囲外として明示します。

断面から姿勢を読み取れない断層は、近隣20km・走向差35度以内の断面資料と、地域資料を参考に設定した角度の分布を使います。距離と走向に応じた重みを付け、角度と傾斜側を候補ごとに推定します。傾斜側が反対の候補は別々に扱います。方向だけが公表されている断層は、その傾斜側を保って角度を推定します。これらは姿勢の類似性を仮定した推定であり、重みは較正した確率ではありません。方向が曖昧な場合は反対側の候補も別シナリオに残します。適用可能な資料がなければ単一の地下断層面を作らず、地表線を保持します。

都市圏活断層図の短線は公式凡例に従い「低下側」として読みます。逆断層と分かる場合は反対側が傾斜側になりますが、断層型が不明な場合は低下側だけから傾斜側や角度を決めません。陸上2地点・海底6地点の記号の読み取り画素・出典画像ハッシュ・解釈は `data/structure/gsi-fault-kinematics.json` に記録しています。海底では低下側が反対の枝も区別します。

中央構造線の海域は、地質断層線がない部分についてNaviの全国主要活断層帯に収録された10本の原トレースを個別の構造候補にしています。重複する活断層DBの概略線は二重の遮断面にしません。地域評価の浅部高角度を低い重みの事前分布として使い、75度という代表値を全枝での測定値とはしません。深部の30度を各枝の浅部へ一律に移しません。枝を地下で自動的に結合しません。

国土地理院の解説書にある先山断層のトレンチでの10〜20度西傾斜や、鳴門南断層の局所的な65〜75度北傾斜は、局所資料として記録しています。トレンチの位置・深度を登録せずに全断層へ同じ角度を与えることはしません。

## 海域の音響基盤

岩淵ほか（2000）「反射法音波探査に基づく大阪湾の基盤と活構造」 Fig.22の基盤深度等深線から5点を座標化し、陸海を含む補助構造領域で盆地/基盤の共通境界を求め、陸域の構造選択にも反映します。図の基盤と原凡例との対比は構造上の仮説であり、音響基盤から特定の花崗岩相を決めません。

`data/structure/marine.json` に元画像の目盛り・ピクセル・座標系の仮定・水平500m/深度300mという誤差の設定値を保存します。これらは本モデルで置いた仮定であり、実際の誤差を測定した結果ではありません。旧日本測地系の使用は年代に基づく仮定で、原図で確認済みとはしません。2本の等深線上の5点は相関する読み取り値で、独立した多数の観測ではありません。全海域の地質図・全等深線を取り込んだものではありません。

海域の構造領域は−3000mまでです。沖合の計算上端0mは海底の実測値ではありません。海底地形・海底露頭の原凡例区分は未導入です。海域の岩相を陸域の22単元のどれかで埋めることはせず、補助の基盤境界だけを別表示します。表示する基盤面も読み取り点から4km以内に限定します。
